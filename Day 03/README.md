Some 20 commands in linux

1. pwd \-\> present working directory  
2. ls \-\> list all folder in a directory.  
3. cd \-\> change the current directory.  
4. mkdir \-\> make directory.  
5. rm \-\> remove directory.  
6. cp \-\> copy  
7. mv \-\> move/rename  
8. touch \-\> create a empty file  
9. cat \-\> display file content  
10. nano \-\> open a file in a nano txt editor  
11. vim \-\> open a file in vim editor  
12. clear \-\> clear the terminal screen  
13. ps \-\> show running process.  
14. top \-\> show the live process uses  
15. htop \-\> interactive process monitoring tool  
16. kill \-\> stop the process using PID.  
17. df \-h \-\> show disk space usage.  
18. du \-sh \-\> show size of a folder.  
19. free \-h \-\> show memory and swap uses  
20. uname \-a \-\> display system and kernel info  
21. whoami \-\> current user  
22. ping \-\> check network connection  
23. chmod \-\> change file permission  
24. chown \-\> change file ownership  
25. grep \-\> searches text inside file  
26. dig \-\> check the dns name resolution  
27. curl \-\> send request url/api
